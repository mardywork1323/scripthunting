Get the current date and time in C

Read the clock and format it as YYYY-MM-DD HH:MM:SS or ISO 8601.

now.cnow.cppProgram.csnow.mjsnow.py
#include <stdio.h>
#include <time.h>

int main(void) {
    time_t now = time(NULL);
    char buf[64];
    strftime(buf, sizeof buf, "%Y-%m-%d %H:%M:%S", localtime(&now));
    printf("%s\n", buf);
    return 0;
}
Build & run
gcc now.c -o now && ./now
