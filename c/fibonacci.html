Fibonacci numbers in C

Iterative nth Fibonacci number. Fixed-width integers overflow after fib(93).

fib.cfib.cppProgram.csfib.mjsfib.py
unsigned long long fib(unsigned n) {
    unsigned long long a = 0, b = 1;
    while (n--) {
        unsigned long long t = a + b;
        a = b;
        b = t;
    }
    return a;   /* exact up to fib(93) */
}
Build & run
gcc fib.c -o fib && ./fib
