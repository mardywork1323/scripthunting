Find the smallest and largest value in C

Get the minimum and maximum of a list in one call or one pass.

minmax.cminmax.cppProgram.csminmax.mjsminmax.py
#include <stddef.h>

/* Requires n > 0. */
void min_max(const int *a, size_t n, int *min, int *max) {
    *min = *max = a[0];
    for (size_t i = 1; i < n; i++) {
        if (a[i] < *min) *min = a[i];
        if (a[i] > *max) *max = a[i];
    }
}
Build & run
gcc minmax.c -o minmax && ./minmax
  • Function only. Call it from your own main() before building.
  • The caller must pass at least one element.
