Random integer in a range in C

Pick a whole number between min and max, such as a dice roll.

random.crandom.cppProgram.csrandom.mjsrandom.py
#include <stdlib.h>
#include <time.h>

/* Call once at startup: srand((unsigned)time(NULL)); */
int rand_between(int min, int max) {   /* inclusive */
    return min + rand() % (max - min + 1);
}
Build & run
gcc random.c -o random && ./random
  • Function only. Call it from your own main() before building.
  • rand() is fine for games and tests, not for passwords or tokens.
