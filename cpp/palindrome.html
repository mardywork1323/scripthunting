Check if a string is a palindrome in C++

Ignores case, spaces and punctuation, so “A man, a plan, a canal: Panama” counts.

palindrome.cpalindrome.cppProgram.cspalindrome.mjspalindrome.py
#include <algorithm>
#include <cctype>
#include <string>

bool isPalindrome(const std::string& s) {
    std::string t;
    for (unsigned char c : s)
        if (std::isalnum(c)) t += static_cast<char>(std::tolower(c));
    return std::equal(t.begin(), t.begin() + t.size() / 2, t.rbegin());
}
Build & run
g++ -std=c++17 palindrome.cpp -o palindrome && ./palindrome
