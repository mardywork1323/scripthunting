Parse and create JSON in C++

Turn JSON text into objects and back again.

json.cjson.cppProgram.csjson.mjsjson.py
#include <iostream>
#include <string>
#include <nlohmann/json.hpp>

int main() {
    auto j = nlohmann::json::parse(R"({"name":"Ana","age":31})");
    std::string name = j["name"];
    int age = j.value("age", 0);
    std::cout << name << " is " << age << '\n';

    j["city"] = "Oslo";
    std::cout << j.dump(2) << '\n';   // pretty-printed JSON
}
Build & run
g++ -std=c++17 json.cpp -o json && ./json
  • Uses the header-only nlohmann/json library.
