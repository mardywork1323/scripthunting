Read a file line by line in C++

Open a text file and handle it one line at a time without loading it all into memory.

read.cread.cppProgram.csread.mjsread.py
#include <fstream>
#include <iostream>
#include <string>

int main() {
    std::ifstream file("input.txt");
    if (!file) { std::cerr << "Cannot open input.txt\n"; return 1; }

    for (std::string line; std::getline(file, line); )
        std::cout << line << '\n';
}
Build & run
g++ -std=c++17 read.cpp -o read && ./read
