Binary search a sorted array in C#

Find an item's index in O(log n). The array must already be sorted.

bsearch.cbsearch.cppProgram.csbsearch.mjsbsearch.py
using System;

int[] sorted = { 1, 3, 5, 7, 9 };
int i = Array.BinarySearch(sorted, 7);         // 3
int missing = Array.BinarySearch(sorted, 4);   // negative means not found
Build & run
dotnet run
  • Paste into Program.cs of a console app (dotnet new console). Needs .NET 6 or later.
