Use a hash map or dictionary in C#

Insert, look up, delete and loop over key-value pairs.

map.cmap.cppProgram.csmap.mjsmap.py
using System;
using System.Collections.Generic;

var ages = new Dictionary<string, int> { ["Ana"] = 31 };
ages["Bo"] = 25;                              // insert or overwrite

if (ages.TryGetValue("Ana", out int age))
    Console.WriteLine(age);                   // 31

ages.Remove("Bo");
foreach (var (name, a) in ages)
    Console.WriteLine($"{name} {a}");
Build & run
dotnet run
  • Paste into Program.cs of a console app (dotnet new console). Needs .NET 6 or later.
