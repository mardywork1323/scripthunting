Stack and queue in C#

Last-in-first-out and first-in-first-out containers.

stack.cstack.cppProgram.csstack.mjsstack.py
using System;
using System.Collections.Generic;

var stack = new Stack<int>();         // last in, first out
stack.Push(1);
stack.Push(2);
Console.WriteLine(stack.Pop());       // 2

var queue = new Queue<int>();         // first in, first out
queue.Enqueue(1);
queue.Enqueue(2);
Console.WriteLine(queue.Dequeue());   // 1
Build & run
dotnet run
  • Paste into Program.cs of a console app (dotnet new console). Needs .NET 6 or later.
