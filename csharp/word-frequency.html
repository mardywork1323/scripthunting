Count how often each word appears in C#

Split text into words and tally each one, most common first where the language makes that easy.

words.cwords.cppProgram.cswords.mjswords.py
using System;
using System.Linq;

var text = "the cat and the hat and the bat";
var freq = text.Split(' ', StringSplitOptions.RemoveEmptyEntries)
               .GroupBy(w => w)
               .OrderByDescending(g => g.Count());

foreach (var g in freq)
    Console.WriteLine($"{g.Key}: {g.Count()}");
Build & run
dotnet run
  • Paste into Program.cs of a console app (dotnet new console). Needs .NET 6 or later.
