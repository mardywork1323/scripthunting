Define a class with a constructor in JavaScript

A small Player type with a name, hit points and a method that changes them.

player.cplayer.cppProgram.csplayer.mjsplayer.py
class Player {
  #hp;

  constructor(name, hp) {
    this.name = name;
    this.#hp = hp;
  }

  hit(dmg) {
    this.#hp = Math.max(0, this.#hp - dmg);
  }

  get hp() {
    return this.#hp;
  }
}

const p = new Player("Ana", 100);
p.hit(30);
console.log(`${p.name} has ${p.hp} HP`);

node player.mjs
