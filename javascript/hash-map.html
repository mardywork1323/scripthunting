Use a hash map or dictionary in JavaScript

Insert, look up, delete and loop over key-value pairs.

map.cmap.cppProgram.csmap.mjsmap.py
const ages = new Map([["Ana", 31]]);
ages.set("Bo", 25);       // insert or overwrite
ages.get("Ana");          // 31
ages.has("Cy");           // false
ages.delete("Bo");

for (const [name, age] of ages) console.log(name, age);
Build & run
node map.mjs
