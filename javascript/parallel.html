Run work in parallel in JavaScript

Start several jobs at once and collect their results.

parallel.cparallel.cppProgram.csparallel.mjsparallel.py
const urls = [
  "https://api.github.com/repos/nodejs/node",
  "https://api.github.com/repos/python/cpython",
];

const results = await Promise.all(
  urls.map((u) => fetch(u).then((r) => r.json()))
);
console.log(results.map((r) => r.full_name));
Build & run
node parallel.mjs
  • Promise.all runs I/O concurrently. For CPU-heavy work use worker_threads.
