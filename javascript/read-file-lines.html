Read a file line by line in JavaScript

Open a text file and handle it one line at a time without loading it all into memory.

read.cread.cppProgram.csread.mjsread.py
import { createReadStream } from "node:fs";
import { createInterface } from "node:readline";

const rl = createInterface({ input: createReadStream("input.txt") });
for await (const line of rl) {
  console.log(line);
}
Build & run
node read.mjs
  • Node.js. Save as .mjs so top-level await works.
