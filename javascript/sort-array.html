Sort an array or list in JavaScript

Ascending, descending and by a field. Watch out for JavaScript's default string sort.

sort.csort.cppProgram.cssort.mjssort.py
const nums = [5, 2, 9, 1, 7];
nums.sort((a, b) => a - b);   // without a comparator, sort() compares as strings

const desc = nums.toSorted((a, b) => b - a);   // returns a new array
